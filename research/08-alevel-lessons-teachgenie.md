# Research note — A-Level hub, Lessons player, Teach Genie (2026-10-28)

## /a-level hub (original: mathsgenie.co.uk/a-level)

Layout: `H3 "A Level Subjects" + book icon`, `Search subjects...` input,
`Popular` heading + horizontally-snapping card shelf, `Other subjects`
heading + responsive grid. Every card is a **3D deck tile**:

- outer tile: pastel bg + blurred cover image (`opacity-30 blur-2xl saturate-200`, hover `opacity-50`)
- inner deck: `aspect-[3/4]`, `perspective: 1500px; perspective-origin: left`,
  `transform-style: preserve-3d`
- stack: 6 white layers (`border-2 border-gray-200`) at `translateZ(20/18/12/6/0/-6)`
  with growing insets — deck-of-cards depth
- top card: cover image + white `border-2` ring + bold white title bottom-center
- hover: deck tilts open (original `group-hover:[transform:rotateY(-30deg)]`)
- covers hot-linked from `assets.mathsgenie.co.uk/subject-covers/*.jpg`
  (map captured for all 50 subjects; see src/lib/alevel-subjects.ts)

Subjects with multiple boards open a **"Choose exam board" popover**
(white rounded-2xl border-2, muted header, board links; Maths: AQA, Edexcel,
OCR, Edexcel (Legacy), OCR (MEI), WJEC, CCEA). Direct-link subjects navigate
straight away (e.g. Accounting → /a-level/accounting/aqa).

## Lesson player (original: /gcse/maths/edexcel/{topic}/lessons)

Full-screen focus mode: top bar (←, ⋯, Sign up), left icon rail (lessons icon
active), thin progress bar, centered column, footer `‹ Back · Ask Genie ·
Next/Continue/Check`. Step types observed live:

1. **teach** — orange icon + orange heading ("Using place value"), paragraphs
   revealed one per click; previously-revealed paragraphs fade to ~35% ink
2. **mcq** — blue icon + cyan "Multiple Choice Question", question with
   KaTeX math, A–D options with circular letter badges; on answer the correct
   option's badge turns solid green with a check, picked-wrong turns red ✕,
   others fade; full-width green/red feedback band slides in above the footer
   ("Great job!" / explanation)
3. **fill ("Complete the sentence")** — inline underline input with keyboard
   glyph + disabled Check until input
4. completion: progress bar full, celebration state

Our recreation: `src/components/player/LessonPlayer.tsx` (adds Ask Genie hint
popover + topics drawer + localStorage completion tracking
`mg-lessons-done` + events). Content: `data/lessons/edexcel.json` — 134
lessons (29 hand-authored flagships incl. the original's own place-value
lesson; the rest generated by scripts/gen_lessons.py with computed answers).
Routes: `/gcse/maths/[board]/lessons` (hub with grade accordions + rings) and
`/gcse/maths/[board]/[topic]/lessons` (player; lesson lookup by topic title
so every board serves the same content).

## Teach Genie (original: login-gated)

Original shows the "Welcome back" auth wall (Google/Apple/Microsoft/email)
with testimonials. Post-login flow documented from member-area research:
pick topics → teach Baby Genie (Feynman) → see what stuck. Our interactive
recreation runs the same conversation shape locally:
`src/components/member/TeachGenieSession.tsx` (landing → picker ≤3 topics →
4-exchange chat with Genie probes → strengths/gaps summary + confidence).

## Gotchas hit

- calling a helper exported from a "use client" module in a server component
  throws at runtime — lesson data access lives in server-safe
  `src/lib/lessons.ts`
- popovers inside an `overflow-x-auto` shelf are clipped (overflow-y computes
  to auto) — the board menu renders `position: fixed` at the card's rect and
  flips above when short on space (original portals its Base UI menu)
- localStorage progress reads must use `useSyncExternalStore` (no setState in
  effect), with a cached raw-string snapshot for identity stability
